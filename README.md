## 📌 About the Project

An event-based static website for **Google Cloud Community Days (GCCD) Kolkata 2025** — demonstrating web development skills through a real-world tech community event.

## 🌐 Live Preview

Open `index.html` with Live Server or visit: `http://127.0.0.1:5500/index.html`

## 🗂️ Project Structure

```
GCCD-kolkata-2025/
├── index.html       # Main HTML page
├── styles.css       # All styling (Google brand colors, responsive design)
├── script.js        # Interactivity (countdown, schedule filter, form, animations)
└── package.json     # Vite dev dependencies
```

## ✨ Features

- **Hero Section** — Live countdown timer to event date (March 15, 2025)
- **About** — Benefits grid with hover animations
- **Speakers** — 4 featured speaker cards with images and topic tags
- **Schedule** — Filterable timeline (All / Keynotes / Workshops / Panels)
- **Networking** — Opportunity cards + community stats
- **Registration** — Animated form with success notification
- **Responsive** — Mobile-friendly with hamburger navigation

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Page structure |
| CSS3 | Styling, animations, CSS variables |
| Vanilla JavaScript | DOM interactions, countdown, filtering |
| Vite | Dev server & build tool |
| Google Fonts (Google Sans) | Typography |

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

Or simply open `index.html` directly with VS Code Live Server.
